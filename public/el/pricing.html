Προγράμματα

Τα δημόσια μοντέλα είναι δωρεάν. Επιλέξτε πρόγραμμα επί πληρωμή αν θέλετε η εργασία σας να παραμένει ιδιωτική, για εσάς ή την ομάδα σας.

Δωρεάν

Για εργασία που μπορεί να δει ο καθένας.

0 $ τον μήνα

  • Απεριόριστα δημόσια μοντέλα
  • Αποθήκευση και κοινή χρήση της εργασίας σας
  • Χωρίς ιδιωτικά μοντέλα

Ατομικό

Για εργασία που θέλετε να μείνει ιδιωτική.

5 $ τον μήνα

  • 20 ιδιωτικά μοντέλα
  • Τα ιδιωτικά μοντέλα είναι ορατά μόνο σε εσάς
  • Απεριόριστα δημόσια μοντέλα

Οργανισμοί

Για μια ομάδα που συνεργάζεται.

12 $ ανά χρήστη, τον μήνα

  • 200 ιδιωτικά μοντέλα
  • Τα μέλη μπορούν να βλέπουν και να επεξεργάζονται κοινόχρηστα μοντέλα
  • Απεριόριστα δημόσια μοντέλα
  • Δωρεάν δοκιμή 30 ημερών

Σχετικά με τα προγράμματα

Τι είναι ένα μοντέλο;

Ένα μοντέλο είναι ένα υπολογιστικό φύλλο με αριθμούς, εκτιμήσεις και υπολογισμούς. Μπορείτε να δοκιμάσετε ένα στο πρόχειρο χωρίς λογαριασμό.

Ποιος μπορεί να δει την εργασία μου;

Ο καθένας μπορεί να δει ένα δημόσιο μοντέλο. Ένα ατομικό ιδιωτικό μοντέλο είναι ορατό μόνο στον κάτοχό του. Τα ιδιωτικά μοντέλα ενός οργανισμού είναι κοινόχρηστα με τα μέλη του.

Μπορώ να αλλάξω ή να ακυρώσω το πρόγραμμά μου;

Η χρέωση γίνεται μηνιαία. Μπορείτε να αλλάξετε ή να ακυρώσετε τη συνδρομή σας από την πύλη πληρωμών του λογαριασμού σας.

Τι θα συμβεί στα ιδιωτικά μοντέλα αν ακυρώσω;

Δεν θα μπορείτε να δείτε ή να επεξεργαστείτε τα ιδιωτικά μοντέλα σας μέχρι να εγγραφείτε ξανά.

Πώς μπορώ να πληρώσω;

Γίνονται δεκτές Visa, Mastercard και American Express.

Υπάρχουν εκπτώσεις για εκπαιδευτικούς ή μη κερδοσκοπικούς οργανισμούς;

Ναι. Επικοινωνήστε μαζί μας για να ρωτήσετε για έκπτωση για τον οργανισμό σας.
